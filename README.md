# 📚 Nền tảng Chia sẻ và Quản lý Tài liệu (Document Sharing Platform)

## 📖 Giới thiệu 
Dự án này là một nền tảng web ứng dụng được phát triển nhằm mục đích cung cấp không gian lưu trữ, chia sẻ và quản lý tài liệu hiệu quả. Hệ thống được thiết kế với kiến trúc RESTful API chặt chẽ, tối ưu hóa trải nghiệm người dùng và dễ dàng mở rộng.

## 🚀 Các chức năng cốt lõi (Core Features)
Hệ thống tập trung giải quyết các luồng nghiệp vụ chính sau:
* **Xác thực & Phân quyền (Authentication):** Đăng ký, đăng nhập và bảo mật tài khoản.
* **Quản lý Tài liệu:** Hỗ trợ người dùng đăng tải (Upload) và tải xuống (Download) các tài liệu.
* **Hệ thống Bộ sưu tập Yêu thích (Favorite Collections):** 
  * Áp dụng quan hệ đa chiều ($N - M$).
  * Người dùng có thể tạo và quản lý nhiều thư mục/mục yêu thích.
  * Một thư mục có thể lưu trữ nhiều tài liệu và một tài liệu có thể nằm trong nhiều thư mục khác nhau của người dùng.

## 💻 Công nghệ sử dụng (Tech Stack)
* **Backend:** Java Spring Boot .
* **Frontend:** Vue.js (Xây dựng giao diện người dùng tương tác dạng SPA - Single Page Application).
* **Database:** MySQL
